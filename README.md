# Simple Data Filtering Using Python

## Project Overview

This project demonstrates simple data filtering using Python.

A student dataset is created using Python dictionaries. The records contain student names, ages, marks, and departments. Different conditions are applied to filter the required student records.

## Objectives

- Create student records using Python.
- Filter students based on marks.
- Filter students based on age.
- Filter students based on department.
- Apply multiple conditions together.

## Technologies Used

- Python
- Google Colab

## Dataset

The dataset contains the following fields:

- Name
- Age
- Marks
- Department

## Filtering Conditions

### 1. Marks

Students with marks greater than or equal to 75 are selected.

### 2. Age

Students with age less than or equal to 21 are selected.

### 3. Department

Students belonging to the AI & ML department are selected.

### 4. Multiple Conditions

Students satisfying all three conditions are selected.

## Concepts Used

- Python Lists
- Dictionaries
- List Comprehension
- Conditional Filtering
- Comparison Operators
- Logical Operators

## Results

- Students with marks >= 75: 4
- Students with age <= 21: 4
- AI & ML students: 3
- Students satisfying all conditions: 2

## Conclusion

This project demonstrates how Python can be used to filter structured data based on different conditions. It helped in understanding conditional filtering, comparison operators, logical operators, and list comprehensions.
